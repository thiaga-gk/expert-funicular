# TDD Loop

1. Select one story/acceptance criterion.
2. Add/identify a failing unit or integration test.
3. Implement the smallest layer-local change.
4. Run focused tests.
5. Run full suite.
6. Add/update golden scenario only when approved semantics changed.
7. Run synthetic fleet through real pipeline.
8. Run independent verifier and `/code-review low` when available.
9. Commit only after evidence is captured.
